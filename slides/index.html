Opensend · Training series

We're All Software Developers Now

Four 60-minute sessions, one per week, on working with Claude. Each session is teaching, then hands-on, with a small assignment that feeds the next session. Everyone finishes with a repo a teammate can clone and run.

  • Session 1

    Don't ship slop.

    An AI policy update, slop and slop grenades, the sender's contract, the pre-send checklist. Ends with everyone signed in to GitHub.

  • Session 2

    GitHub as your backend

    What Claude does with Git under the hood, README and CLAUDE.md, scheduled tasks, what never goes in a repo, and why the repo is the source of truth.

  • Session 3

    Break the work into steps

    Inputs, numbered steps, outputs. Raw, derived, and historical files. Audit trails, and re-runs that don't break history.

  • Session 4

    Same result, every time, for everyone

    Procedures as files, scripts that make spreadsheets, golden examples, the handoff test, and generative vs. decision models.
