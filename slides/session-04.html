Hands-on · 30 minutes

Pairs swap repos and run each other's workflow

  1. Your golden example, made-up data, is in golden/ and pushed
  2. Get your partner's work: gh pr checkout 12 (their pull request number)
  3. Run it cold, without asking them. Write down every question you'd have asked
  4. Compare with their golden output
  5. Hand back the gaps, then git switch alex-kim (yours)
