What is AI slop?

Four kinds of slop

  • Output nobody asked for
  • Claims the sender can't defend
  • Length that hides the answer
  • Work that transfers effort to the reader

A pre-send checklist

Three questions before you hit send

  1. Does it answer a question someone asked?
  2. Could you defend every number?
  3. Is it shorter than what it replaces?

It's a file in the starter repo: checklists/pre-send.md

Hands-on · 30 minutes

Leave signed in to GitHub

  1. Create a GitHub account at github.com/signup, with your Opensend email
  2. Open a terminal: Mac Cmd + Space → Terminal · Windows: Windows key → Terminal or PowerShell
  3. Install Git, then the GitHub CLI, following docs/install-github-cli.md
  4. Sign in: gh auth login → GitHub.com · HTTPS · Yes · web browser · copy the code, press Enter
  5. Check it: gh auth status shows your username
  6. Tell Git who you are, then check you can reach the repo: gh repo view fueled-io/os-claude-advanced-training

Checklist with "done when" for every step: sessions/01/exercise.md
