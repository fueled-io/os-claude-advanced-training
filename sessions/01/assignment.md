# Session 1 assignment

**Didn't finish in class?** Finish these before Session 2.

1. [ ] **Install Claude Code and Claude Desktop.** Follow [`docs/install-claude-code.md`](../../docs/install-claude-code.md).
   *Done when* both are installed, you are signed in to each with your Opensend Claude account, and Claude Code answers a test message in the terminal.
   Stuck? Claude can help: [`docs/setup-with-claude.md`](../../docs/setup-with-claude.md).
2. [ ] **Confirm `gh auth status` succeeds.** Open a terminal, type `gh auth status`, press Enter.
   *Done when* it shows your GitHub username and says you are logged in.
3. [ ] **Download your copy of this public repo.** In a terminal, type this and press Enter:

   ```
   gh repo fork fueled-io/os-claude-advanced-training --clone
   ```

   It makes your own copy on GitHub (a fork) and downloads it into a folder called `os-claude-advanced-training` in your home folder. Session 2, step 2, explains it in more detail.
   *Done when* that folder exists. Type `cd os-claude-advanced-training` and press Enter to go into it.
4. [ ] **Read [`CONTRIBUTING.md`](../../CONTRIBUTING.md).** This repo is public, and so is everything you push to it from Session 2 on. It lists what must never be committed: client details, real business numbers, personal information, passwords and keys, internal links.
   *Done when* you could name three things that never go in this repo.
5. [ ] **Use the pre-send checklist once.** Before you send something Claude helped you write this week, run it through [`checklists/pre-send.md`](../../checklists/pre-send.md).

Session 2 starts in your copy of this repo, so steps 1 to 3 have to work first.
